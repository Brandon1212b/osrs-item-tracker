# OSRS Item Tracker

I want to create a website that tracks items in OSRS. It should use the most up to date live prices. The whole intent of this website is a way to track gear and skilling items. It’s different from other sites because it’s not about flipping, it’s meant for the regular player who just wants to get gear when it’s cheap or good buying opportunities for items that are used is the wikis skilling guide (only popular or efficient methods).
